		The Massive Calculator
---------------------------------------

Edit php.ini to include:
/php_Calculator
/php_Calculator/modules
/php_Calculator/Log
/php_Calculator/DB
/php_Calculator/modules/test
/php_Calculator/comments
/php_Calculator/f_suggestions

Copy php_Calculator to your web root.
Change permissions so that the www-data user has write permissions to DB and Log Directory.
If you change the name of the calculator, you will need to then change everywhere that is calling the old name.

You will also have to change the path below to reflect the name change. As well as during the installation on the admin page.

In your browser go to http://<hostname>/php_Calculator/admin and enter in all the appropriate information
Click "Start Install"
This will create the database and tables using the username and password that you set. This will also create the log file in the Logs Directory.
