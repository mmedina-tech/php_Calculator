The Massive Calculator

1) Copy the Massive_Calculator Directory to your target machine
2) cd into the Massive_Calculator Directory and run Calculator_Install.sh
3) In the URL insert localhost/Massive_Calculator.web/admin
4) Fill out the form
	All the information in the form will then be written to a 
	config file to be used throughout the program.
	You can find the config file in the Massive_Calculator.cgi/Database directory
	called dbconfig.py
	
5) Click the "Start Install" button.
	The Database and log files will be created at this point.
	If the Database and log files already exist then the page will tell you as such.

6) Click the "Get Started" link
