		The Massive Calculator
---------------------------------------

Prereqs:
- PHP with PDO MySQL enabled
- A pre-created MariaDB user with access to the target database

Recommended install (CLI):
1) From the repo root, run:
   php scripts/install.php
2) This creates DB tables and writes DB/calculator.config.local.php.

Optional web installer:
1) Generate a one-time token:
   php scripts/install.php --web-token
2) Visit http://<hostname>/<base>/admin and enter the token + DB details.

Notes:
- The installer is locked after success (install.lock). Delete it to re-run.
- Do not commit DB/calculator.config.local.php (contains secrets).
- If you change the base URL, update it via the installer.
- You can symlink the repo into your web root; ensure the web server allows
  FollowSymLinks and has write access to DB/ and Logs/.
