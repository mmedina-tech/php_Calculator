        Create A New Calculator Module
--------------------------------------------------


To create a new module for the Massive Calculator there are a few things that you need to do.

First, clone the project to your local workstation.

Now that we have a local repo of the project we can begin the work.

go into the modules directory in the php_Calculator and we are going to create a new module.

please run from modules this command: utils/mkcalc_mod.sh -t <mod_name> -a

This will create a new module for you. lets break down the flags.

-t <mod_name>: this is where you set the module name
-a: this is saying that you want all the options, shebang line, synopsis line, license block,
author block, and open the module for editing after the file is created. dont worry the file will be
opened using the editor that you have specified in your .bashrc file.

everything is already layed out for you to go straight into adding the new info.

___________________________________________________________________________________________________________

All modules are structured as follows:

Requires Once: FormulaBase.php

Construtor function:
    We need to call the entries array from the FormulaBase class
    $this->entries = array(
        (For the first of every new module you need to initialize new netry)
        1 => FormulaBase::create_func_entry(
            (first parameter is the name of the formula),
            (second parameter is the annonymous function that has the calculation of the formula),
            (third parameter is the input array for the formula),
            (fourth parameter is the array for showing how the formula is constructed so that people can do the formula long hand if they wish)
        ),
        (Each formula set after this first one is formated like this.)
        FormulaBase::create_func_entry(
            (and follow the parameters from above)
        ),
    );
